📖 The Data Model

Every creature is a dossier. Here is what rides inside each record.

FieldDescription
titleCreature name (e.g. Kraken — The Abyssal Leviathan)
description / textShort tagline and full mythological lore
imagePublic-domain artwork URL
first_recorded / eraEarliest written record + historical era
origin[]Cultural lineage — Greek, Norse, Celtic, Chinese…
creature_type[]Dragon, Sea Monster, Spirit, Leviathan…
element[]Elemental affinity — Fire, Water, Shadow, Spirit…
habitatMountains, Deep Ocean, Forest, Sky, Underworld…
danger_levelThreat scale 0–10 (the bar above is a 9.5)
abilities[] / weakness[]Known powers and vulnerabilities
is_shapeshifter / is_immortalBooleans for the truly unsettling

🚀 Getting Started

Three commands. One bestiary.

# From turing-marketplace/mythical-creatures/app/
npm install
npm run dev        # local preview
npm run compile    # production build
npm run package    # build + zip ready for Marketplace import

The generated mythical-creatures.zip bundles the SN site export, indexed content, and compiled SPA template. Import it via Turing → Marketplace → Install from file, and the bestiary springs to life.
