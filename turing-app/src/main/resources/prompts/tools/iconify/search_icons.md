Search the Iconify icon registry for icons matching a free-text query, and return a list of Iconify identifiers (formatted as `<prefix>:<name>`, e.g. `mdi:home`, `tabler:user`, `ph:lightning`). Use this tool whenever you need to pick a contextually appropriate icon for an entity being authored — Intents, AI Agents, Custom Tools, MCP Servers, Search Sites, etc. Each result is a stable identifier the frontend will render via the Iconify framework. Prefer short, generic English keywords (e.g. "home", "shopping cart", "graduation hat", "chat", "lightbulb") rather than full sentences. The tool searches across the curated icon collections supported by this project: Lucide, Tabler, Material Design Icons (mdi), Phosphor (ph), Solar, and Heroicons. Parameters: `query` (string, required) — the search term in English; `limit` (integer, optional, default 32, max 96) — maximum number of results to return. After you receive the list, pick ONE identifier that best matches the entity's meaning and use it as the icon value. Do NOT invent icon names — only use names returned by this tool.
