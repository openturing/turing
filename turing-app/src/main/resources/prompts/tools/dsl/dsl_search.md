Execute a search using the full Elasticsearch Query DSL. The query_body parameter accepts the complete Elasticsearch _search request body as a JSON string, including: query (match, bool, term, range, etc.), from/size for pagination, sort, _source field filtering, highlight, aggregations (terms, avg, sum, stats, etc.), post_filter, and more. This is the most powerful search tool — it supports all 40 Elasticsearch query types and 35 aggregation types. The query is automatically translated to the site's configured search engine (Elasticsearch, Solr, or Lucene). Example query_body: {"query":{"bool":{"must":[{"match":{"title":"search"}}],"filter":[{"term":{"status":"published"}}]}},"size":10,"aggs":{"by_type":{"terms":{"field":"type"}}}}
