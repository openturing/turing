Returns statistics about the knowledge base: total indexed files, total embedding chunks,
total file size, and a breakdown of files by content type.

Use this tool when the user asks:
- "How many documents are in the knowledge base?"
- "What's in my knowledge base?"
- "Show me knowledge base stats"
- "How much content has been indexed?"

No arguments required.

Returns:
    Summary statistics including file counts, chunk counts, size, and type breakdown.
