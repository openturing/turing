Gets the current date and time for a given timezone.
Use this tool when the user asks what time it is, the current date, or the date/time in a specific city or timezone.
Args:
    timezone (str): An IANA timezone identifier (e.g., 'America/Sao_Paulo', 'Europe/London', 'Asia/Tokyo', 'US/Eastern'). Use 'UTC' if no timezone is specified.
Returns:
    The current date and time formatted for the requested timezone.
