Explain WHY a specific search result ranked where it did, using the site's real ranking signals. Use this when the user asks "why is this #1?", "why did this rank above that?", or "how was this ordered?". Parameters: `index` is the site name; `locale` is the locale code (e.g. "en", "pt") or empty for the default; `query` is the exact search the user ran; `documentId` is the id of the result to explain (omit to explain the top result). The tool re-runs the search and returns the objective ranking breakdown — keyword (BM25) rank, semantic (vector) rank, the HYBRID_RRF fused rank and score, the final position, and any reranker effect. Narrate these factors to the user in plain language and NEVER invent scores that are not in the breakdown. If the site uses keyword-only ranking, say so. This is a trust/transparency feature — be precise and honest about what determined the order.
