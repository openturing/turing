Run a configured AI Agent (chat-flow) headlessly and return its final answer plus any slots it captured. Parameters: agentId (from list_agents), message (the user turn to send the agent), and conversationId (optional — pass the value returned by a previous invoke_agent call to continue the same multi-turn conversation; omit to start a fresh one). The agent runs with its full configuration (persona voice, RAG grounding, tools, and flow logic). The response includes the assistant answer, a "Captured slots" section listing any structured values the flow extracted (e.g. name, email, intent), and the Conversation id to reuse for follow-up turns. Use this to reuse the customer carefully-authored flows from outside the Turing chat widget.
