Answer a question grounded in one site indexed content, with citations, in a single call. This runs a search over the site, feeds the most relevant documents to the LLM, and returns a concise answer that cites its sources as [1], [2], … followed by the matching source list (title + URL). Parameters: site (from list_sites), locale (e.g. en_US; defaults to the site default), question (the natural-language question), and maxSources (1-20, default 5). Prefer this over raw search_site when you want enterprise-truth-grounded prose rather than a list of hits — the citation trail is the auditable defense for the answer. If the indexed content does not contain the answer, the tool says so rather than inventing facts.
