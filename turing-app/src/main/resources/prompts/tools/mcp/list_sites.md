List the enterprise search sites available on this Turing server. Each site is an independently searchable collection of indexed content (a wiki, a product catalog, a policy library, …) with its own fields, locales, and search-engine backend. Optionally pass a name pattern (substring or wildcard) to filter. Returns each site name, status, engine, locales, and description. Call this first to discover what you can search before using search_site, facet_search, or get_site_fields.
