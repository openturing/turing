Find the indexed documents most similar to a block of reference text on one site — a more-like-this / nearest-neighbour search. Pass site, locale, the referenceText to find neighbours of, and maxResults (1-50, default 10). On a site whose engine is configured for semantic/vector search this rides that capability; otherwise it is a full-text similarity. Use it to surface related policies, duplicate content, or "see also" documents given an example passage.
