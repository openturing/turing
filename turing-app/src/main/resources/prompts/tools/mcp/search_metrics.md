Aggregate search metrics for one site from its query log. Returns the top search terms, how many times each was run, and the average number of results each returned, plus the total search count over the period. Parameters: site (from list_sites), period (today | this-week | this-month | all-time; defaults to all-time), and rows (1-50, default 10). Use it to understand what users look for most and how well the index serves those queries.
