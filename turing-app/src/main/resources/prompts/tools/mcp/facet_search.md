Faceted drill-down over one site: run an optional query and return the value counts (buckets) for a single facet field, instead of the documents themselves. Parameters: site, locale, query (optional — empty means facet across all documents), and facetField (a field reported as a facet by get_site_fields). Use it for content audits and analytics, e.g. "how many pages exist per product category" or "which authors published in this section".
