Run a semantic / full-text search over one site and return the most relevant indexed documents with their id, score, and source fields. Parameters: site (from list_sites), locale (e.g. en_US; defaults to the site default), query (the natural-language or keyword search text — leave empty to match all documents), and maxResults (1-50, default 10). The query is matched against the full document text and routed to the site configured search engine (Solr, Lucene, or Elasticsearch). This is the primary tool for grounding an answer in the customer enterprise content; cite the returned documents.
