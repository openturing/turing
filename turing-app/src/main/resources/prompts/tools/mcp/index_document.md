Index (create or update) a single document into a site. WRITE tool — requires the mcp:write scope and must be enabled by the operator (turing.mcp-server.write-enabled). Parameters: site (from list_sites), locale (e.g. en_US; defaults to the site default), and documentJson (a JSON object for the document — must include a unique "id" field, plus any indexed fields such as title, text, url, type). The document is queued for indexing through the same pipeline as the import API (engine routing, schema auto-create, RAG fan-out); indexing is asynchronous, so success means "accepted", not "committed". Use it to onboard content without the admin console.
