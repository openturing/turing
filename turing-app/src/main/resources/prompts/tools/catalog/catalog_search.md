Search a Turing catalog (Semantic Navigation site) with a plain natural-language request and get back a numbered, cited list of the most relevant items, ranked by objective relevance only. Prefer this over dsl_search when the user is shopping or browsing a catalog: you pass the user's prose directly in the `query` parameter (e.g. "online master's in data science under 20k near São Paulo") and the tool grounds it against the site's declared fields for you — you do NOT need to write an Elasticsearch query body. Parameters: `index` is the catalog site name; `locale` is the locale code (e.g. "en", "pt") or empty for the default; `query` is the user's natural-language request. The reply lists each result as `[n] title / URL / key attributes`. Answer the user using ONLY the returned results and cite each claim with its bracketed number, e.g. [1][3]. If no results are returned, tell the user and suggest how to refine the search instead of guessing.
