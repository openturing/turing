# Atlas Store return policy (sample)

| Category | Return window | Restocking fee | Notes |
|---|---|---|---|
| Electronics | 30 days | 15% if opened after 14 days | Original packaging required |
| Home & Kitchen | 30 days | None | Unused only |
| Outdoors | 60 days | None | Lifetime warranty on defects |
| Fashion | 45 days | None | Tags attached |
| Toys & Games | 30 days | None | — |

## Universal rules

- The window is measured from the **purchase date**.
- **Final-sale** items (clearance, gift cards) are non-returnable.
- Refunds are issued to the original payment method within **5–7 business days**
  of the warehouse receiving the return.
- Approved returns ship free via a **prepaid label** emailed with the RMA.
- Exchanges ship as soon as the return is scanned by the carrier.
