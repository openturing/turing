# 🔍 Turing React SDK — Storybook

Welcome to the **@viglet/turing-react-sdk** component library! This Storybook is an
**interactive, runnable map** of every hook and UI component in the SDK — from classic
faceted search all the way to streaming **RAG chat**, **agentic tool-calling**,
**generative UI**, **realtime voice**, and **co-browsing copilots**.

> 💡 **Every story runs offline.** Each demo *simulates* its hook with local state
> and the marketplace fixtures — no backend, no API keys, no network. So you can
> click, type, stream, and fill slots right here to feel exactly how a hook behaves
> before wiring it to a live Turing instance.

---

## What is Turing React SDK?

The Turing React SDK provides **headless hooks** and **unstyled UI components** for building
custom search _and_ conversational AI experiences on top of the **Viglet Turing ES**
Semantic Navigation API. You bring the design; the SDK brings the data, the streaming,
the state machines, and the AI plumbing.

## 📚 Storybook Sections

### 🔎 Hooks — Search foundations

- **useTuringSearch** — core search hook for programmatic (non-URL) mode
- **useTuringFacets** — facet data with toggle / clear actions
- **useTuringPagination** — pagination data with navigation helpers
- **useTuringTabs** — tab-based search navigation
- **useTuringSortOptions** — available sort options for a site
- **useTuringAutoComplete** — autocomplete with debouncing
- **useTuringDocument** — typed field access for custom document fields
- **useTuringSearchHistory** — persisted search history (IndexedDB)
- …plus experiment, flow-state, flow-chooser, handoff and single-slot hooks

### 🧠 Discovery — Smarter retrieval

- **useTuringSimilar** — "more like this" / related-items with a similarity score
- **useTuringSpellCheck** — "did you mean?" corrected-query suggestions
- **useTuringDslSearch** — structured DSL queries (typed filters &amp; expressions)

### 💬 AI &amp; Chat — Conversational &amp; agentic

- **useTuringChat** — streaming RAG chat grounded in search results, with sources &amp; citations
- **useTuringSemanticChat** — tool-calling navigation chat (`search_site`, `get_site_fields`, …)
- **useGenerativeUI** — the LLM emits structured UI items rendered from a component registry
- **useAnswerAsApp** — answers rendered as interactive mini-apps / tool widgets
- **useTuringSlots** — read the live, aggregated slot board of a guided conversation
- **useTuringSlotUpload** — upload files (image / audio / doc) into a chat slot
- **useTuringWorkspace** — per-conversation agent workspace of generated artifacts (SSE)
- **useTuringProactiveCopilot** — anticipatory suggestions based on what the user is doing
- **useTuringUserMemory** — persistent per-user memory that personalises replies
- **useTuringRealtimeVoice** — full-duplex realtime voice agent with realtime tool calls
- **useTuringVoice** — turn-based Web Speech STT / TTS wrapper

### 🛠️ Platform — Ops, info &amp; co-browsing

- **useTuringAnalytics** — typed search / chat analytics events to pluggable sinks
- **useTuringLlmInstances** — list configured LLM models / vendors (build a model picker)
- **useTuringPlatformInfo** — backend capabilities &amp; feature flags for UI gating
- **useTuringResume** — restore a previous conversation and continue it
- **useTuringIntents** — intent detection → action shortcuts
- **useCoBrowseSearch** — synchronized search view the agent can drive alongside chat

### 🎨 UI Components

- **TuringSearchBar** / **TuringSearchField** — search inputs (simple &amp; compound w/ autocomplete)
- **TuringResultList** / **TuringPagination** — render results &amp; pagination via render props
- **TuringChatMessage** / **TuringCitedAnswer** / **TuringSourceChips** — chat &amp; citation primitives
- **TuringToolActivity** / **TuringGenerativeContent** / **TuringCodeBlock** / **TuringMarkdown** / **TuringD2Diagram** — rich-content renderers
- All are **headless &amp; design-agnostic** — skin them via `classNames`, `labels`, `icons`, or CSS tokens

### 🎭 Showcases (Inspired by turing-marketplace)

- **🐉 Mythical Creatures** — fantasy bestiary with element badges and danger bars
- **🚀 Space Missions** — space exploration with agency / outcome facets and HUD cards
- **🎵 Vinyl Records** — record store with album art, star ratings, and condition grading

## Quick Start — Search

```tsx
import { TuringProvider, useTuringSearch } from "@viglet/turing-react-sdk";

function App() {
  return (
    <TuringProvider config={{ site: "my-site", locale: "en_US" }}>
      <SearchPage />
    </TuringProvider>
  );
}

function SearchPage() {
  const { documents, searchQuery, status } = useTuringSearch();

  return (
    <div>
      <input
        placeholder="Search..."
        onKeyDown={(e) => {
          if (e.key === "Enter") searchQuery(e.currentTarget.value);
        }}
      />
      {status === "loading" && <p>Loading...</p>}
      {documents.map((doc) => (
        <div key={doc.url}>
          <h3>{doc.title}</h3>
          <p>{doc.description}</p>
        </div>
      ))}
    </div>
  );
}
```

## Quick Start — RAG Chat

```tsx
import { TuringProvider, useTuringChat } from "@viglet/turing-react-sdk";

function ChatPage() {
  const { messages, send, isStreaming } = useTuringChat();

  return (
    <div>
      {messages.map((m) => (
        <article key={m.id} data-role={m.role}>
          <p>{m.content}</p>
          {/* sources stream in alongside the answer */}
          {m.sources?.map((s) => (
            <a key={s.url} href={s.url}>{s.title}</a>
          ))}
        </article>
      ))}

      <form
        onSubmit={(e) => {
          e.preventDefault();
          const input = e.currentTarget.elements.namedItem("q") as HTMLInputElement;
          send(input.value);
          input.value = "";
        }}
      >
        <input name="q" placeholder="Ask anything…" disabled={isStreaming} />
      </form>
    </div>
  );
}
```

> The hook surfaces exact signatures may vary — open each hook's **Docs** tab in the
> sidebar for its real return shape, options, and a copy-pasteable `Usage` snippet.
