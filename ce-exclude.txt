# ── Semantics ────────────────────────────────────────────────────────────────
# Patterns are gitignore-style, matched against repo-root-relative paths:
#   - one pattern per line; blank lines and lines starting with `#` are ignored
#   - `**` matches across directories; trailing `/` matches a directory
#   - a leading `!` RE-INCLUDES a path that an earlier pattern excluded
# Paths matched here are STRIPPED from the assembled public tree by the publish
# script (T357) before the squash-snapshot commit. The secret-scan gate (T358)
# is the backstop, NOT the policy — a missed path must never reach the public,
# indexed, un-deletable mirror.
#
# Doctrine: default-DENY for docs/** design content; default-ALLOW for code.
